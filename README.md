## Smart Delivery Planning – Fractional Knapsack

Smart Delivery Planning is a **C-based menu-driven program** that uses the **Fractional Knapsack Greedy Algorithm** to maximize the total value of packages carried by a delivery vehicle with limited capacity.

The program accepts package values and weights, calculates the **Value/Weight ratio**, and sorts packages in decreasing order of their ratio. Packages with the highest ratio are selected first. If a complete package cannot fit into the remaining capacity, a suitable fraction of the package is selected.

### Key Features

* Fractional Knapsack using Greedy Method
* Value/Weight ratio calculation
* Sorting based on ratio
* Partial package selection
* Menu-driven interface
* Uses C structures, arrays, and functions
* Displays selected packages, total weight, and maximum value

This project demonstrates the practical application of the **Greedy Algorithm** for solving optimization problems with limited resources.
